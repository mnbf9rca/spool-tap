# CoreS3 SE mounts

The printed mount setup is assembled and in testing.

- `cores3_wedge_45.stl` is the 45° rear wedge for the CoreS3 SE, with four M3 screw paths and two pockets for 32 × 3 mm magnets.
- `nfc_dock.stl` is a separate holder for the Grove NFC reader, with an open connector end and two pockets for 8.34 × 8.34 × 2 mm magnets.

The STLs are generated by `prototype_mounts.py`, which requires CadQuery.
Run `python cad/prototype_mounts.py` from the repository root to regenerate them.

Place the wedge magnet-pocket face on the build plate; support the large pocket roofs and upper crossbar.
Place the dock magnet-pocket face on the build plate.

Attach the wedge with four M3 screws before bonding the magnets into their outward-facing pockets.
Check screw length against the CoreS3 inserts; the screw heads seat behind the wedge's mounting ring.
The fit, magnetic holding force, and reader dock are still being tested on the hardware.
